# protocol/AGENTS.md

This is the contract. Both `server/` and `android/` depend on it; it depends on nothing —
zero runtime dependencies, zero dev dependencies beyond TypeScript and Vitest
(CODE_STANDARD.md N1).

- A wire type is declared here (`src/types.ts`), documented in `PROTOCOL.md`, and given a
  fixture in `fixtures/` **before** it is used in `server/src` or mirrored in Kotlin.
- `fixtures/*.json` are hand-written, never generated by code. Both test suites parse them and
  assert a byte-identical round trip.
- Bumping `PROTOCOL_VERSION` (`src/version.ts`) is a breaking-change signal — see F2. Don't
  bump it for an additive change.
